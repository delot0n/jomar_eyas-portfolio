# Assets

assets/avatar/avatar.png            -> your pixel avatar (square, transparent or solid background).
                                       Shown automatically in the hero window once the file exists.
assets/projects/<project-id>/main.jpg   -> main preview (16:10 recommended, e.g. 1600x1000).
assets/projects/<project-id>/*.jpg      -> extra screenshots (list them in projects.js > screenshots).

Any file name/format works (jpg, png, webp). Just make the path in projects.js match.
